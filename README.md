# 🧠 Local Vision AI

An AI-powered application that analyzes content, answers questions, and generates PowerPoint presentations using local AI models.

## ✨ Features
- AI-powered content analysis
- Ask AI and get answers
- Automatic slide generation
- PowerPoint export

## 🛠️ Technologies
Python • Ollama • JavaScript • HTML • Node.js
